# Animation graphs

Runs Source 2's Animgraph 2 animation graphs (`.vnmgraph`). Animgraph 2 is taken from the
[Esoterica](https://github.com/BobbyAnguelov/Esoterica) animation system, and this is a C# port of
it.

| Folder         | What is in it                                                |
| -------------- | ------------------------------------------------------------ |
| `Definitions/` | Node structure headers. Generated by `Misc/SchemaConverter`. |
| `Runtime/`     | Node behavior.                                               |
| .              | Node factory, utilities and entry point.                     |

A graph is played through `AnimationGraph`, which builds the nodes, feeds them their control
parameters and returns the pose.

## Differences from Esoterica

- There is no pose task list. Esoterica nodes register tasks (sample, blend, IK) that are executed
  after the graph has updated. In our version a node computes its pose during its update and returns it. Bone
  masks still go through a task list, because layers pass them down as one.
- Source 2 adds a few nodes, in `Runtime/ValveNodes.cs`, and there is support for client defined nodes too.
